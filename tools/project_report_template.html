等待時間與 CPU 時間有什麼不同？
等待時間（wall time）是從啟動到完成的實際時間，包含排程與 I/O 等待。
CPU 時間是編譯器與其子程序實際使用處理器的時間；多工等待不等於 CPU 運算。
分析仍有狀態與時間上限；碰到上限會保留「未確認」，不會硬算成已證明。
